# С чего начать

Это проект «Страж инвестиций»: учебный стенд, где правило для продажи бумаг пишется обычными словами в чате, а бот
исполняет его на искусственной бирже со стаканом заявок. В конце виден честный итог: сколько продано и сколько
получилось бы, если бы ничего не делать. Реальных денег, счетов и заявок здесь нет.

## Как скачать

**Самое простое: архивом.** Откройте <https://github.com/mess1ahbenz/strazh-invest>, нажмите зелёную кнопку
**Code → Download ZIP** и распакуйте. Прямая ссылка:
<https://github.com/mess1ahbenz/strazh-invest/archive/refs/heads/main.zip>.

**Через git** (если нужно получать обновления):

```bash
git clone https://github.com/mess1ahbenz/strazh-invest.git
cd strazh-invest
```

Аккаунт на GitHub для скачивания не нужен: репозиторий публичный.

## Как запустить за пять минут

Нужен либо Docker, либо Python 3.12.

**Вариант 1. Docker** (ничего больше ставить не надо):

```bash
docker compose up --build
```

Откройте <http://127.0.0.1:8000>.

**Вариант 2. Python:**

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.main
```

На Windows вместо `.venv/bin/` пишите `.venv\Scripts\`. Адрес тот же: <http://127.0.0.1:8000>.

Никаких ключей и токенов для запуска не нужно. Telegram и языковая модель включаются по желанию, см. `README.md`.

## Что нажимать

1. Кнопка **«Пример в чат»** отправляет готовое правило: «если цена упадёт на 10% от цены покупки, продай всё, не
   дешевле 850 рублей». Страж покажет, как он его понял. Подтвердите кнопкой **«Включить»**.
2. Нажмите **«−50%»**: цена мгновенно падает вдвое.
3. Нажмите **«К итогу»** и прочитайте итог. Правило сработало, но покупателей от 850 ₽ нет, поэтому ничего не продано.
   Это главная мысль стенда: стоп-правило не гарантирует продажу, и система говорит об этом прямо, а не рисует
   красивую картинку.

Остальные сценарии (А — постепенное падение, В — исчезновение покупателей, Г — падение с восстановлением, Д — толпа ботов на
одном рынке) выбираются в списке над графиком. Кнопка «Остановить торги» есть в разделе управления рынком.
Сценарий показа для жюри на три минуты: [DEMO.md](DEMO.md).

## Как это устроено

```
Чат (слова) → Страж (разбор + подтверждение) → правило → Торговый бот → Биржа со стаканом → Итог
```

Главное решение: **агент и торговый бот разделены**. Страж понимает слова и объясняет результат, но денег не трогает.
Бот — обычный код без языковой модели: он получает события рынка и отправляет заявки. Поэтому ошибка модели не может
сама продать бумаги: правило включается только по кнопке, а ответ модели перед этим проверяется кодом.

| Куда смотреть | Что там |
|---|---|
| `app/market/` | Биржа: общий стакан, приоритет цены и времени, ограниченный спрос |
| `app/bot/` | Торговый бот: условия, заявки, частичное исполнение |
| `app/agent/` | Страж: разбор правил, проверка ответов модели, диалог, Telegram |
| `app/sim/` | Время симуляции, сценарии, виртуальные боты (толпа) |
| `app/report.py` | Итог: все числа считаются здесь |
| `app/api.py` | HTTP-сервер, комнаты посетителей сайта, чат |
| `web/` | Интерфейс на чистых HTML, CSS и JavaScript |
| `tests/` | 213 тестов: `.venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest` |

Подробнее: [ALGORITHM.md](ALGORITHM.md) — как считаются цены, исполнение и итог.

## Честно о границах

- Это **стоп-лимит заявка, объяснённая словами**. У брокера такой тип заявки уже есть, и в боевом контуре правило
  ставилось бы им. Ценность стенда в объяснении гэпа, честном сравнении с удержанием и модели толпы. Подробнее — в
  [relevance.md](review/relevance.md), там же слабые места идеи.
- Рынок искусственный. Как поведёт себя настоящий, стенд не знает.
- Проверено: тесты, приёмочный сценарий, клики в браузере, адаптер песочницы T-Invest на ОФЗ. Не проверено: вебхук
  Telegram на настоящем сайте и настоящая языковая модель. Полный список: [RESULTS.md](RESULTS.md) и
  [LIMITATIONS.md](LIMITATIONS.md).
- Перед публикацией проект атаковали два раза, найденное исправлено: [adversarial.md](review/adversarial.md).

## Правила обращения с секретами

Файл `.env` с токенами в репозиторий не попадает и попадать не должен. Если вы подключаете свой Telegram-бот или ключ
модели, кладите их только в `.env` (образец — `.env.example`) и никогда не отправляйте в чат или коммит.
