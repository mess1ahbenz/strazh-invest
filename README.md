# Страж инвестиций

Учебный симулятор · искусственные данные. Реальных заявок нет, настоящие счета не подключены.

Цепочка: **правило словами в чате → подтверждение → алгоритмический бот → искусственный рынок со стаканом → честный итог**.

Страж (агент) принимает правило, показывает, как его понял, и объясняет результат. Торговый бот — отдельный код без
языковой модели: он получает рыночные события, отправляет заявки через интерфейс брокера и отслеживает исполнение.

## Что это и чего это не делает

По функции правило Стража — это стоп-лимит заявка: «если цена упала до порога, продать, но не дешевле минимума».
У брокера такой тип уже есть (`STOP_ORDER_TYPE_STOP_LIMIT` с `GOOD_TILL_DATE`), и в боевом контуре правило ставилось бы
им, а не собственным ботом. Ценность стенда в другом:

- **объяснение гэпа.** Обвал на 50% за секунду: правило сработало, но покупателей от минимальной цены нет. Стенд
  показывает это на стакане и в итоге, а не делает вид, что стоп «спас» позицию;
- **честный итог.** Каждый прогон сравнивается с удержанием: «с ботом», «без бота», разница в рублях;
- **толпа.** До 200 ботов с тем же правилом продают в один стакан, и видно, как одинаковые стопы роняют цену.

## Три способа запуска

### Сайт в интернете

Публичный режим (`STRAZH_MODE=public`): каждый посетитель получает свою изолированную комнату в памяти, владелец входит
паролем и видит основную комнату с Telegram.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/mess1ahbenz/strazh-invest)

Что заполнить при развёртывании и как устроен бесплатный тариф: [docs/DEPLOY.md](docs/DEPLOY.md).

### Docker Compose на своём компьютере

```bash
docker compose up --build
```

Панель: <http://127.0.0.1:8000>. Порт открыт только на локальном адресе. Токены не нужны.

### Без Docker

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.main
```

Тесты: `.venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest`.

Сценарии без браузера: `.venv/bin/python scripts/run_scenarios.py`.
Приёмочный путь против запущенного локального сервера: `.venv/bin/python scripts/acceptance.py http://127.0.0.1:8000`.
Он сбрасывает симуляцию и удаляет правила, поэтому на рабочую комнату владельца его не направляйте.

## Что подключается и как

Все настройки необязательны, образец в `.env.example`. Файл `.env` не попадает в git и образ, секреты не уходят в браузер.

**Telegram.** Создайте бота у @BotFather и заполните три поля:

```bash
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...          # уведомления уходят только сюда
TELEGRAM_ALLOWED_USERS=...    # кто может управлять
```

Без любого из них Telegram выключен, а в панели работает встроенный тестовый чат с тем же обработчиком команд.
Один токен бота нельзя одновременно опрашивать с двух машин: если бот работает на сайте (вебхук), на своём
компьютере оставьте `TELEGRAM_BOT_TOKEN` пустым.

**Языковая модель.** `ANTHROPIC_API_KEY`. Без ключа честный демо-режим: понятны только шаблоны команд, бот так и пишет.
На сайте запросы к модели ограничены общим бюджетом `STRAZH_LLM_HOURLY_LIMIT` (300 в час), сверх него — шаблоны.

**Песочница T-Invest.** Только для проверки адаптера, см. `docs/TINVEST.md`.

## Что внутри

| Каталог | Назначение |
|---|---|
| `app/market/` | Биржа: общий стакан, приоритет цены и времени, ограниченный спрос |

## Безопасность

- **Локально** панель слушает только `127.0.0.1`, запросы с чужим `Host` или `Origin` отклоняются. На внешнем адресе
  локальный режим не запустится.
- **На сайте** посетитель управляет только своей комнатой в памяти: чужие правила, чат и Telegram ему недоступны.
  Комната владельца открывается паролем (`STRAZH_OWNER_PASSWORD`, не короче 12 символов), cookie подписана и живёт 12 часов.
  Небезопасную конфигурацию сервер отказывается запускать.
- Ограничены частота запросов, размер тела (16 КБ при любой передаче), диапазоны чисел, число комнат и запросов к модели.
  Пустые комнаты, которые никто не открыл, уступают место новым посетителям.
- Telegram принимает только разрешённых пользователей; вебхук проверяет секретный заголовок.
- Настоящих счетов в проекте нет. Единственный внешний брокерский адрес — песочница, и он зашит в адаптер.
